# 🎮 Petualangan Bilangan Bulat

Game edukasi matematika SMP Kelas 7 (Fase D) — berpetualang melewati 6 wilayah, mengumpulkan Kristal Matematika, dan mengalahkan Raja Kegelapan Minus!

## 🗺️ 6 Wilayah
1. 🚪 **Gerbang Angka** — bilangan positif, negatif, nol; membandingkan & mengurutkan
2. 🌉 **Jembatan Garis Bilangan** — letak bilangan, pergerakan kanan–kiri
3. 🌳 **Hutan Penjumlahan** — penjumlahan bilangan bulat
4. 🕳️ **Gua Pengurangan** — pengurangan; kurang negatif = tambah
5. ⛰️ **Gunung Perkalian & Pembagian** — aturan tanda (berwaktu ⏱️)
6. 🏰 **Kastel Tantangan Akhir** — operasi campuran, soal cerita, HOTS (lawan bos 👹)

## ✨ Fitur
- 60 soal terverifikasi (8 soal acak per wilayah), 8 tipe interaksi: pilihan ganda, benar/salah, mengurutkan (tap-to-place), garis bilangan interaktif, mencocokkan, isian angka, pilih langkah penyelesaian, soal cerita kontekstual
- Skor 100/jawaban, bonus kecepatan +50, kombo +30, 3 nyawa per wilayah, bintang 1–3, 3 lencana 🏅
- Rekap hasil belajar + topik yang perlu dipelajari lagi
- Progres tersimpan otomatis di perangkat (localStorage) — tanpa login, tanpa internet
- Responsif: HP, tablet, laptop; efek suara WebAudio (dapat dimatikan)

## 🚀 Cara menjalankan
Buka `index.html` langsung di browser (klik-ganda) — satu file mandiri, tanpa server, tanpa install, tanpa CDN.
